### ภาพวีรชน

ภาพรวมวีรชนประกอบด้วยพระราม หนุมาน และทศกัณฐ์ อ้างอิงแนวคิดจากวรรณคดี/ตำนานไทยดั้งเดิม (public-domain folklore) และออกแบบการแต่งกาย สี ท่าทาง และการจัดภาพใหม่ ไม่มีการอ้างว่าเป็นภาพที่มนุษย์วาด หรือว่าภาพที่สร้างนี้เป็น public-domain โดยอัตโนมัติ

**สรุป prompt:** ภาพตัวละครสามช่องสำหรับเกม RAMA; พระรามผิวเขียวถือคันศร, หนุมานวานรขาว, ทศกัณฐ์ยักษ์เขียว; เครื่องทรงไทยประดับทอง ผ้าโทนแดง/เขียว รายละเอียดแบบภาพวาดแฟนตาซีคุณภาพสูง พื้นกระดาษสีอุ่นและลายพฤกษา; ไม่ใส่ข้อความ โลโก้ หรือลายน้ำ; เป็นการออกแบบใหม่โดยไม่คัดลอก character art จากเกมหรือภาพยนตร์ร่วมสมัย

ภาพที่สร้างต้นทางเป็น PNG แล้วเข้ารหัสเป็น WebP คุณภาพ 88 เพื่อใช้งานบนเว็บ โดยไม่เปลี่ยนองค์ประกอบภาพ

ไฟล์ที่บันทึก:

```text
public/art/hero-atlas.webp
SHA-256: d69dd0d5b84c186229c6e695a06e4e4554443af8078a641afb05e29d0f4630f4
ขนาดไฟล์: 590,314 bytes
```

เมื่อเปลี่ยนไฟล์ภาพ ให้ปรับ checksum และบันทึกวิธีสร้าง/แก้ไขตามจริง การอ้างอิงตำนานดั้งเดิมไม่ได้เป็นการอนุญาตให้คัดลอกรูปแบบภาพของงานดัดแปลงร่วมสมัยใด

## วิดีโออ้างอิง

ใช้วิดีโอที่ผู้ใช้แนบเพื่อวิเคราะห์ genre, user flow, มุมกล้อง และบรรยากาศเท่านั้น ไม่มีการ commit วิดีโอ ภาพจับหน้าจอ บุคคลที่ปรากฏในคลิป หรือ artwork ของเกมในวิดีโอเข้ามาใน production assets ของ RAMA
