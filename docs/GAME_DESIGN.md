# RAMA — Game Design

เวอร์ชันเริ่มต้น: 24 พฤศจิกายน 2569 (2026-11-24)

## เป้าหมาย

สร้างเกมวางแผนธีมตำนานไทยที่เล่นได้จริงตั้งแต่เข้าเมืองจนจบแคมเปญ ผ่านเบราว์เซอร์บนคอมพิวเตอร์และมือถือ ให้ผู้เล่นสลับการตัดสินใจระหว่างพัฒนาเศรษฐกิจ เพิ่มกองกำลัง และเลือกเวลารุกคืบ โดยไม่ต้องรอเป็นชั่วโมงก่อนเห็นผล

## สิ่งที่เห็นในวิดีโออ้างอิง

วิดีโอที่ผู้ใช้แนบมีความยาวประมาณ 52 วินาที ช่วงที่เห็นเกมแสดงองค์ประกอบต่อไปนี้:

- เมืองไทยมุมมองไอโซเมตริก มีป้ายระดับสิ่งก่อสร้างและแปลงผลิตทรัพยากร
- ทรัพยากรไม้ หิน สำริด และข้าว พร้อมผลผลิตต่อชั่วโมง
- หน้าขุนพลที่มีพลังชีวิต ประสบการณ์ ค่าสถานะ และการแจกแต้มความสามารถ
- หน้าฝึกทหาร พร้อมราคาและเงื่อนไขปลดล็อก
- แผนที่โลก จุดเมือง เส้นทางการเดินทัพ และเวลานับถอยหลัง
- UI สีครีม การ์ดมุมมน และรายละเอียดสีแดง/ทอง

บางหน้ามีข้อความเกี่ยวกับเผ่า พันธมิตร และระบบที่เกี่ยวข้องกับ agent แต่คลิปไม่ได้ให้รายละเอียดกติกาหรือ API ครบถ้วน จึงไม่ตีความว่าโครงการนี้มีฟังก์ชันเหล่านั้นโดยอัตโนมัติ

RAMA นำแนววงจรการเล่นและบรรยากาศมาพัฒนาเป็นเกมใหม่ ใช้การจัดวางเมือง ตัวเลขกติกา แผนที่ โค้ด และภาพประกอบของโครงการเอง ไม่มีการนำภาพหน้าจอ โมเดล เสียง หรือ source code ของเกมในคลิปเข้ามาเป็น asset

## วงจรการเล่น

**ผลิตทรัพยากร → อัปเกรดเมือง → ฝึกทหาร → พัฒนาวีรชน → ส่งทัพ → รับรายงานและรางวัล → เปิดพื้นที่ถัดไป**

ผู้เล่นเริ่มต้นด้วยพระราชวังระดับ 2 อาคารอื่นระดับ 1 พลพิทักษ์ 8 นาย พลธนู 6 นาย และทรัพยากรเพียงพอสำหรับเริ่มงานหลายประเภท มีคิวก่อสร้าง คิวฝึก และคิวเดินทัพได้ประเภทละหนึ่งรายการพร้อมกัน

ภารกิจ 6 บทช่วยสอนตามลำดับ: ก่อสร้างสำเร็จ → ฝึกทหารรวม 6 นาย → ชนะการศึก → พระราชวังระดับ 3 → พิชิต 3 พื้นที่ → พิชิตลงกา ผู้เล่นต้องกดรับรางวัลทีละบท แต่ความคืบหน้าที่ทำล่วงหน้าจะยังนับ

## เศรษฐกิจและเมือง

| ระบบ | ค่าตั้งต้น/กติกา |
| --- | --- |
| ทรัพยากรเริ่มต้น | ไม้ 700 · ศิลา 620 · สำริด 350 · ข้าว 1,100 |
| ผลผลิตต่อนาทีที่ระดับ 1 | ไม้ 42 · ศิลา 34 · สำริด 22 · ข้าว 66 |
| ความจุต่อทรัพยากร | `2,000 + พระราชวัง × 1,000 + ตลาด × 500` |
| โบนัสตลาด | เพิ่มผลผลิตทุกชนิด 8% ต่อระดับที่สูงกว่าระดับ 1 |
| ระดับสูงสุด | สิ่งก่อสร้างทุกแห่งระดับ 6 |
| ข้อจำกัดระดับอาคาร | ระดับเป้าหมายต้องไม่สูงกว่าพระราชวังเกิน 1 ระดับ |
| เวลาอัปเกรด | 12–38 วินาทีตามชนิด/ระดับที่เล่นได้; engine กำหนดเพดาน 45 วินาที |
| ราคาอัปเกรด | ราคาฐาน × `1.55^(ระดับปัจจุบัน − 1)` ปัดขึ้น |
| ผลผลิตย้อนหลัง | สูงสุด 2 ชั่วโมงต่อการกลับเข้าเกม และไม่เกินความจุคลัง |

อาคารมีหน้าที่ชัดเจน: โรงเลื่อย/เหมืองศิลา/โรงหล่อ/นาข้าวผลิตทรัพยากร, พระราชวังปลดล็อกและเพิ่มคลัง, ตลาดเพิ่มคลังและผลผลิต, ค่ายทหารปลดล็อกหน่วยและลดเวลาฝึก, ประตูนครกับเทวสถานช่วยลดการสูญเสีย และเทวสถานเพิ่มพลังวีรชน

## กองทัพและผลรบ

| หน่วย | พลังโจมตี | เวลาฝึกฐาน/นาย | ปลดล็อก |
| --- | ---: | ---: | --- |
| พลพิทักษ์ | 12 | 5 วินาที | ค่ายทหารระดับ 1 |
| พลธนู | 18 | 6 วินาที | ค่ายทหารระดับ 1 |
| วานรศึก | 32 | 7 วินาที | ค่ายทหารระดับ 2 |

ฝึกได้ 1–50 นายต่อรายการ และทหารทั้งหมดรวมที่กำลังออกศึกไม่เกิน 250 นาย การส่งทัพใช้ข้าว 8 หน่วยต่อทหาร 1 นาย ระบบจัดส่วนผสมทหารที่มีให้โดยสลับชนิดตามลำดับ เพื่อให้จำนวนที่ส่งตรงกับที่ผู้เล่นเลือก

พลังรบคำนวณจากผลรวมพลังโจมตีทหาร บวกพลังพระรามและเทวสถาน แต้มโจมตีของพระรามเพิ่มพลังทหาร 4.5% ต่อแต้ม ชนะเมื่อพลังรวมไม่น้อยกว่าพลังฝ่ายตรงข้าม ไม่มีการสุ่มผลรบใน MVP นี้

จำนวนสูญเสียคำนวณจากอัตราส่วนพลังรบกับศัตรู และลดลงด้วยแต้มป้องกัน ประตูนคร และเทวสถาน หน้าเตรียมทัพสามารถแสดงผลคาดการณ์ได้ตรงกับ engine แต้มโชคลาภเพิ่มทรัพยากรที่ได้รับ 3.5% ต่อแต้ม ผลแพ้ยังคืนทหารที่รอดชีวิต แต่ไม่ให้ทรัพยากรและไม่ปลดล็อกพื้นที่ถัดไป

ค่า `defense` ของหน่วยทหารเก็บไว้ในข้อมูลสำหรับพัฒนาบาลานซ์ในอนาคต รุ่นนี้การลดความสูญเสียใช้ค่าวีรชนและอาคาร ไม่ได้นำ `TROOPS.defense` มาเป็นสูตรอีกชั้น

ค่าบาลานซ์ตั้งใจให้เหมาะกับการทดลองเล่นช่วงสั้น การจำลองผ่าน engine จากเซฟเริ่มต้นโดยจ่ายค่าฝึก/ก่อสร้างจริงและรับการสูญเสียจริง สามารถจบครบ 6 พื้นที่และรับครบ 6 ภารกิจในเวลาเกมประมาณ 12.2 นาทีตามกลยุทธ์หนึ่ง ตัวเลขนี้เป็นผลจำลองตรรกะ ไม่ใช่ค่าเฉลี่ยจากการทดลองกับผู้เล่นจริง

## เวลาและเซฟ

`engine.js` แยกจาก DOM และ renderer ใช้เวลาเป็นมิลลิวินาทีที่ส่งเข้าฟังก์ชัน จึงทดสอบคิวและการกลับเข้าเกมโดยไม่ต้องรอเวลาจริงได้ เมื่อหลายคิวเสร็จในช่วงที่ไม่ได้เปิดเกม engine จะเรียงเวลาที่เสร็จและคิดผลผลิตก่อน/หลังอาคารเปลี่ยนระดับอย่างถูกลำดับ

เซฟเป็น JSON เวอร์ชัน 1 มีการจำกัดระดับ ทรัพยากร กองทัพ แต้มวีรชน และรูปแบบคิว รวมถึงปฏิเสธค่าไม่ใช่ตัวเลข/ค่าติดลบที่เป็นอันตรายต่อการคำนวณ การตรวจเซฟนี้มีไว้รักษาความถูกต้องของเกมในเครื่อง ไม่ได้ทำให้ข้อมูลฝั่งผู้เล่นเชื่อถือได้สำหรับการแข่งขันหลายคน

## ทิศทางภาพ

- ฉากเมืองแบบ miniature diorama ใช้ orthographic camera และโมเดลสร้างด้วยโค้ด
- สถาปัตยกรรมหลังคาไทย สีดินเผา ทองเก่า เขียวพืชพรรณ และผิววัสดุด้าน
- UI พื้นสีงาช้าง ตัวอักษรเขียวเข้ม รายละเอียดทอง และพื้นที่ว่างเพื่อให้เมืองเด่น
- แผนที่โลกวาดด้วย SVG ใช้เส้นทาง ป่า แม่น้ำ และป้อมเป็นสัญลักษณ์ที่กดได้
- ภาพวีรชนสร้างใหม่ด้วย image generation และแยกที่มาไว้ใน `ASSET_PROVENANCE.md`

## ขอบเขตต่อไป

รายการต่อไปนี้ยังไม่ใช่ความสามารถที่ส่งมอบในรุ่นนี้:

1. ระบบเลือกเผ่าพร้อมเศรษฐกิจ/ทหารที่แตกต่างกัน และวีรชนหลายตัวที่เลือกใช้ได้จริง
2. รูปขบวนทหาร ทักษะ active การเลือกชนิดทหารที่ส่ง และภาพการรบแบบเคลื่อนไหว
3. server-authoritative simulation, authentication, cloud save และการย้ายข้อมูลข้ามเครื่อง
4. PvP, guild, chat, leaderboard, season และระบบจับคู่
5. API/MCP สำหรับ agent พร้อม permission, rate limit และ audit log ที่ออกแบบแยกต่างหาก
6. PWA/service worker, accessibility audit เพิ่มเติม และ benchmark บนอุปกรณ์มือถือจริง

ก่อนขยายเป็น multiplayer ต้องวาง authoritative clock, idempotent action processing, transaction ของทรัพยากร/กองทัพ และการตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ก่อนเพิ่มหน้าจอสังคมหรือการแข่งขัน
